# flaky_lab — поиск и исправление нестабильных тестов

Учебный проект к практической работе «Нестабильные (flaky) тесты: поиск, диагностика и исправление»
(дисциплина «Поддержка и тестирование программных модулей», Лисевич Арсений, Исп/п23-09.2).

Приложение — «Магазин книг»: сервер на Python, одна страница на HTML/JS, тесты на pytest + Playwright.
Код приложения не менялся, исправлялись только тесты.

## Что внутри

| Папка / файл | Назначение |
| --- | --- |
| `server.py` | сервер магазина, заказы в памяти, обработка 0,3–2 с |
| `conftest.py` | запуск сервера перед тестами, таймауты 5000 мс |
| `pytest.ini` | `base_url`, артефакты падений, маркер `quarantine` |
| `public/index.html` | страница магазина, баннер `?promo=random` |
| `tests/test_task1_timing.py` | задание 1–2: пауза заменена на `expect(...).to_be_visible()` |
| `tests/test_task3_state.py` | задание 3: уникальный пользователь через `uuid.uuid4()` |
| `tests/test_task4_locators.py` | задание 4: локатор по `data-testid` вместо XPath по позиции |
| `tests/test_task5_demo.py` | задание 5: вышел из карантина, ожидание события |
| `bug/` | исходные нестабильные версии тестов |
| `logs/` | вывод всех прогонов, на нём построены таблицы отчёта |
| `screenshots/` | 40 скриншотов по номерам задания |
| `test-results/` | скриншоты, видео и трассировки упавших запусков |
| `.github/workflows/tests.yml` | CI: основной набор без карантина |

## Запуск

```bash
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
playwright install chromium

pytest                                  # основной набор, карантин исключён
pytest -m quarantine --count=10 -q      # карантинный набор, 10 повторов
pytest tests/test_task1_timing.py --count=20 --tb=no -q   # серия повторов
pytest tests/test_task3_state.py -n 3 --tb=no -q -rf      # параллельно, 3 процесса
python -m playwright show-trace test-results/<папка>/trace.zip
```

## Результаты

| Задание | Причина нестабильности | До исправления | После |
| --- | --- | --- | --- |
| 1–2 | фиксированная пауза 1500 мс вместо ожидания события | 6/20, 4/20, 2/20 упало | 20/20 три серии |
| 3 | общий пользователь `guest`, остаточное состояние и гонка | 2 из 3 тестов падают подряд | 5 параллельных прогонов зелёные |
| 4 | XPath по позиции в разметке, случайный баннер | 9/20 и 11/20 упало | 20/20 две серии |
| 5 | тот же тайминг + диагностика по артефактам и карантин | 4 из 10 упало | 20/20 после выхода из карантина |

Основной набор: 6 passed. На этапе карантина (скриншот 38) было 5 passed, 1 deselected; после снятия маркера тест вернулся в основной набор.
Карантинный набор на этапе проверки: 8 passed, 2 failed (статистика ведётся отдельно).

## CI

GitHub Actions на каждый push: Python 3.12, установка зависимостей, `playwright install --with-deps chromium`,
затем `pytest -m "not quarantine" --tb=short -q`. Карантин в CI не блокирует сборку.
